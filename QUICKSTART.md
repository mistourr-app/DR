# 🚀 Быстрый старт Tutorial

## Запуск за 3 шага

### 1. Установите зависимости, соберите CSS и запустите сервер
```bash
npm ci
npm run build:css
npm start
```

### 2. Откройте браузер
```
http://127.0.0.1:5500
```

### 3. Выберите уровень
Нажмите на кнопку **"Обучение (13 рядов)"**

---

## Что вы увидите

### Шаг 1: Движение вперед
```
┌─────────────────────────────────────┐
│ Тапни на клетку впереди чтобы...    │ ← Подсказка
├─────────────────────────────────────┤
│  [ ] [ ] [ ] [ ] [ ]                │
│  [ ] [ ][✓][ ] [ ]  ← Кликните сюда │
│  [ ] [👤][ ] [ ] [ ]  ← Вы здесь    │
└─────────────────────────────────────┘
```

### Что дальше?

После каждого действия подсказка автоматически меняется на следующий шаг.

Всего **14 шагов**: движение и прыжки, подбор предметов, ближний и дальний бой, использование бонусов, вход в арену и атака босса. Tutorial не покрывает все механики игры: defense bonuses, energy, gold и все режимы AI остаются за пределами обучения.

---

## Особенности

✅ **Нельзя ошибиться** - можно кликать только на разрешённые клетки
✅ **Автоматический прогресс** - переход к следующему шагу сам
ℹ️ **Ограниченный scope** - tutorial показывает основной цикл, но не все механики

## Если что-то не работает

### Проверьте консоль браузера
`F12` → вкладка Console

### Проверьте, что файлы на месте
```
DR/
├── main.js
├── renderer.js
├── combat.js
├── tutorial.js
├── styles.css
└── ...
```

### Перезапустите сервер
```bash
Ctrl+C  (остановить)
node server.js  (запустить снова)
```

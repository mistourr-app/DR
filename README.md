# Dungeon Card Crawler

Мобильный пошаговый fast-paced dungeon crawler в жанре rogue-lite.

## Концепция

**Целевая аудитория:** Мужчины 18+, которые хотят получить опыт быстрого dungeon crawler на мобильных устройствах.

**Уникальная фишка:** Очень быстрый геймплей, близкий к раннерам, но с тактической глубиной.

**Технологии:** PWA app на чистом JavaScript с HTML5 Canvas.

## Разработка

### Запуск
Требуется Node.js 20+ (CI использует Node.js 20).

```bash
npm ci
npm run build:css
npm start
```

Игра доступна на `http://127.0.0.1:5500`. Порт можно изменить переменной `PORT`. Сервер слушает только loopback-интерфейс и не предназначен для публичного размещения.

### Проверки
```bash
npm test
npm run lint
npm run typecheck
npm run graphics:check
npm run build:css
git diff --check
```

`npm run build:css` обновляет отслеживаемый `styles.css`; браузеру не нужен Tailwind CDN. `typecheck` проверяет конфигурацию TypeScript, но `checkJs` отключён и не является полной проверкой типов JavaScript.

### Сохранение и редактор уровней

- `localStorage` хранит `dcc_meta` (золото и `upgrades`), `dcc_data_version`, `levelOrder` и `levelVisibility`; прогресс отдельных забегов и разблокировки не сохраняются.
- При `DATA_VERSION = 3` старые порядок и видимость уровней очищаются при следующей загрузке.
- Золото, собранное внутри забега, сразу показывается в счётчике, но сохраняется только при переходе в summary или victory; выход в меню без завершения забега его отменяет.
- Админка сохраняет изменения только в текущей странице. Для постоянного изменения нужно экспортировать уровень и вставить его в `registry.js`.
- `test_arena` и `debug_boss` имеют скрытый статус в registry и не отображаются в обычном меню.

### Кампания Dungeon 1..30

- 30 уровней генерируются из `CAMPAIGN_CURVE` в `registry.js` функцией `buildCampaignLevels`; кривая — единственное место балансировки.
- `id`: `dungeon_01`..`dungeon_30`, `name`: `Dungeon 1`..`Dungeon 30`, поле `difficulty` равно номеру уровня.
- Сложность растёт линейно от первого уровня к последнему: ряды `30 → 75`, `bossHpMultiplier` `1.2 → 5` (24 → 100 HP), `ENEMY` `0.10 → 0.20`, `WALL` `0.15 → 0.30`, а расходники и бонусы наоборот убывают (`HEAL` `0.06 → 0.05`, `AMMO` `0.05 → 0.04`, `ENERGY` `0.06 → 0.04`, `ATTACK_BONUS` `0.05 → 0.03`, `DEFENSE_BONUS` `0.06 → 0.03`, `GOLD` `0.03 → 0.03`).
- Сумма `chances` остаётся в пределах валидатора: 0.56 на первом уровне и 0.72 на последнем при лимите 1.
- Все уровни открыты сразу, последовательной разблокировки нет. Список из 31 кнопки прокручивается: у `#level-buttons-container` включён `overflow-y: auto` и `touch-action: pan-y`.
- Прямой запуск: `?level=dungeon_01`. Прежние id `sector_1`, `sector_2` и `core` удалены, ссылки на них больше не работают.

### PWA и безопасность

- Service worker использует `dungeon-crawler-v26`: навигация network-first с fallback на precache, остальные локальные ресурсы stale-while-revalidate.
- `styles.css` генерируется из `src/input.css` и должен быть закоммичен вместе с HTML/service worker.
- Для офлайн-навигации `admin.html` использует соб precached response; неизвестные navigation requests используют fallback на `index.html`.
- Версия v26 синхронизирована в `index.html` и `sw.js`; при изменении assets нужно обновить обе версии и пересобрать CSS.
- `server.js` проверяет lexical и real path, скрытые файлы, traversal, null/backslash, ограничивает методы `GET`/`HEAD` и добавляет security headers. Он всё ещё отдаёт доступные файлы проекта и не является production web server.

### Структура данных

**RunState:**
- runId, levelId, seed и shared random (идентификатор и генератор забега)
- player (hp, energy, pos, inventory, weapon, hasShotOnCurrentRow, visual)
- boss (hp, pos, inventory, visual, lastMoveX)
- rows (сетка клеток)
- levelPhase ('dungeon' | 'boss_arena')
- turnOwner ('player' | 'processing'; 'boss' используется как внутренний переходный режим)
- goldCollected, goldCommitted
- visualCellSize, scrollY, targetScrollY, floatingTexts, bossTurnScheduled

**MetaState:**
- gold (мета-валюта)
- upgrades (задел для будущей прокачки)

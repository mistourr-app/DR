# Механика движения

## Последовательность хода

При клике игрока на клетку запускается следующая последовательность:

### 1. Проверка хода
```javascript
// run.js: processPlayerMove()
if (!targetCell || targetCell.type === WALL) return;
if (player.energy < energyCost) return;
```
- Проверяется наличие клетки
- Сначала проверяется стена
- Затем проверяется энергия
- Только после этого начинается ход

### 2. Атака врагов "в спину"
```javascript
// run.js: processEnemyTurns()
const attackingEnemies = getEnemiesWhoCanAttack(player.pos.y);
for (const enemy of attackingEnemies) {
  dealDamageToPlayer(enemy.currentHp, enemy);
}
```
- Враги атакуют ДО начала движения
- Только враги с текущего ряда игрока
- Только враги с линией видимости
- Взаимный урон при ближнем бое

### 3. Проверка выживания
```javascript
if (player.hp <= 0) {
  // Игрок погиб, движение отменяется
  endRun('defeat');
  return;
}
```

### 4. Анимация движения
```javascript
// animation.js
play({
  duration: 250,
  onComplete: () => {/* обработка клетки */}
});
```
- Плавное перемещение спрайта игрока
- Длительность 250ms
- Визуальная обратная связь

### 5. Обновление позиции
Позиция клетки обновляется после анимации перемещения. Затем проверяется объект на новой клетке: бонус, расходник, золото, враг или атака.

### 6. Взаимодействие с новой клеткой
Обработка выполняется в общем коде забега. Значения бонусов читаются через `CELL_DEFS[OBJECT_TYPES.ATTACK_BONUS]` и `CELL_DEFS[OBJECT_TYPES.DEFENSE_BONUS]`.

### 7. Завершение хода
```javascript
// run.js: finalizeTurnAfterMove()
turnOwner = 'player'; // Готов к следующему ходу
// hasShotOnCurrentRow сбрасывается только при реальном перемещении
```

## Типы движения

### Бесплатное движение
- На прилегающую клетку следующего ряда (±1 по X, +1 по Y)
- Не тратит энергию
- Подсветка: зеленый цвет

### Платное движение (прыжок)
- На клетку следующего ряда дальше соседней
- Стоимость: `max(0, расстояние по X - 1)` энергии
- Подсветка: фиолетовый цвет

### Атака врага
- Клик на клетку с врагом
- Взаимный обмен уроном
- Подсветка: красный цвет

## Атака "в спину"

Враги атакуют игрока при уходе с их ряда:

### Условия атаки
1. Враг на том же ряду, что и игрок (до движения)
2. Враг видит игрока (нет стен между ними)
3. Враг жив (currentHp > 0)

### Механика
- Атака происходит ДО анимации движения
- Враг наносит урон, равный его текущему `currentHp`, после 150ms-анимации выпада
- Если игрок погибает - движение отменяется
- Если игрок выживает - движение продолжается

### Визуальная обратная связь
- Красное мигание экрана при уроне, прошедшем через защиту
- Всплывающая цифра урона только при положительном уроне HP
- Анимация атаки врага

## Ближний бой

При клике на клетку с врагом **на следующем ряду** (ряд `player.pos.y + 1`):

### Условия
- Враг находится на ряду непосредственно перед игроком
- Клик на клетку с врагом (не на своего ряду!)

### Условия и стоимость
- Враг находится на ряду непосредственно перед игроком
- Клик на клетку с врагом (не на своего ряду!)
- Для дальнего melee по X списывается `max(0, расстояние по X - 1)` энергии
- На врагов **на своём ряду** кликнуть для боя нельзя — можно только стрелять из арбалета или двигаться дальше

### Последовательность
1. Враги с текущего ряда атакуют "в спину" (до движения)
2. Проверка выживания игрока
3. Анимация перемещения игрока на клетку врага (250ms)
4. Короткий тычок (100ms) → взаимный обмен уроном (`processMeleeCombat`)
5. Игрок возвращается на позицию клетки
6. Если враг мёртв — анимация смерти (fade out + сдвиг вверх, 700ms)
7. Если игрок мёртв — экран поражения
8. Завершение хода

### Расчет урона
В ближнем бою базовый урон игрока равен его текущему HP, а ответный урон врага — его оставшемуся `currentHp`. Бонусы атаки расходуются первыми; затем защита цели поглощает урон, а остаток уменьшает HP. Бонус атаки расходуется до защиты, даже если защита полностью перекрывает атаку.

### Смерть врага
- Анимация смерти (fade out)
- Удаление из карт угроз
- Флаг `threatMapsDirty = true`
- Очистка клетки

## Дальний бой (арбалет)

### Условия
- Враг в пределах дальности (≤3 клетки)
- Есть заряды арбалета
- Линия видимости не заблокирована

### Механика
- Урон: 3 + бонусы атаки
- Расход: 1 заряд
- Враг не отвечает
- Можно стрелять не двигаясь
- Не более одного выстрела за ход

### Последовательность
1. Проверка условий
2. Расход 1 заряда и вычисление урона с attack bonuses
3. Анимация вспышки (100ms)
4. Возврат изображения (100ms)
5. Нанесение урона и проверка смерти врага
6. Обновление карт угроз
7. Возврат хода игроку; флаг «уже стрелял» сбрасывается только после перемещения или следующего хода босса

## Карты угроз (Threat Maps)

Система отслеживания зон видимости врагов:

### Структура
```javascript
{
  alert: Map<cellKey, Set<enemyId>>,  // Враг видит игрока
  idle: Map<cellKey, Set<enemyId>>    // Враг в зоне видимости
}
```

### Обновление
- При смерти врага: удаление из всех клеток
- При движении игрока: пересчет alert/idle
- Флаг `threatMapsDirty` для оптимизации

### Визуализация
- Alert: оранжевый 25% за врага
- Idle: красный 25% за врага
- Наложение от нескольких врагов; итоговая прозрачность ограничена 100%

## Боссфайт

Особая механика для последних 2 рядов:

### Отличия от обычного движения
- Горизонтальное перемещение (только по X)
- Выстрел из арбалета можно сделать до перемещения; сам выстрел не передает ход боссу
- Перемещение или атака клеткой завершает ход игрока и передает его боссу
- Передача хода боссу после перемещения или атаки клеткой (игрок → босс)
- Динамическая генерация клеток

### Последовательность хода
1. Игрок может сделать выстрел из арбалета — ход остаётся у игрока
2. Игрок перемещается или атакует клеткой — ход передаётся боссу
3. Проверка победы над боссом
4. Ход босса (AI)
5. Проверка поражения игрока
6. Генерация новых клеток

### AI босса
Три профиля поведения:
- **Агрессивный** (>60% HP): повышенный приоритет атакующих клеток и attack bonuses
- **Сбалансированный** (25-60% HP): смешанная оценка клеток
- **Защитный** (<=25% HP): приоритет лечения и defense bonuses, штраф за выбор колонки игрока

AI не выбирает немедленный возврат на предыдущую клетку босса, если есть другие варианты. В колонке игрока выстрел из арбалета разрешён, в том числе при нулевой горизонтальной дистанции; при наличии ammo он имеет приоритет перед melee-бонусом. После перемещения в колонку босса доступные attack bonuses могут быть использованы автоматически перед передачей хода.

## Энергия

### Восстановление
- Не восстанавливается автоматически
- Только через предметы (+10 энергии)

### Расход
- Прыжок: `max(0, расстояние по X - 1)` энергии
- Пример: прыжок на 2 клетки = 1 энергия

### Стратегия
- Экономия для критических прыжков
- Подбор предметов энергии
- Планирование маршрута

## Анимации

### Движение игрока
- Длительность: 250ms
- Плавная интерполяция
- Callback после завершения

### Атака врага
- Выпад: 150ms, возврат: 150ms
- Визуальный эффект
- Красное мигание экрана

### Смерть врага
- Длительность: 700ms
- Fade out и сдвиг вверх
- Удаление после завершения

### Выстрел из арбалета
- Длительность зависит от очереди анимаций
- После попадания запускается следующий этап хода
